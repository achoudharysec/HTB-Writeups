# Hack The Box Write-ups

A collection of professional penetration testing reports documenting my solutions to Hack The Box (HTB) machines. These reports demonstrate the methodology used to identify, exploit, and document security vulnerabilities in a controlled lab environment.

---

## Objectives

This repository is intended to:

- Practice penetration testing methodologies.
- Improve technical reporting skills.
- Document the exploitation process in a professional format.
- Build a public cybersecurity portfolio.

---

## Machines Covered

| Machine | Difficulty | Primary Topic |
|----------|------------|---------------|
| Meow | Very Easy | Telnet |
| Fawn | Very Easy | Anonymous FTP |
| Appointment | Very Easy | SQL Injection |
| Sequel | Very Easy | Misconfigured MariaDB |

| Three | Very Easy | Misconfigured AWS S3 Bucket |
| Lame | Easy | Samba RCE |

## Report Structure

Each report follows a consistent penetration testing methodology:

- Objective
- Enumeration
- Exploitation
- Initial Access
- Privilege Escalation *(where applicable)*
- Risk Analysis
- Root Cause
- Evidence
- Remediation
- Conclusion
